How long does a format changeover take on this beverage filling line 5000bph?

With a standardised guide set the changeover is around 12 minutes. The first change on a new 250–500 ml format takes longer because the guide set has to be set and taught.

How are changeovers recorded for traceability?

The 4-inch HMI stores the recipe per format and the parameters can be exported. For a mid-size beverage producers operation running audits, request the export format in writing.
